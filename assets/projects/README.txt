DOSSIER DES PROJETS DU PORTFOLIO

Placez ici vos captures d’écran et vidéos. Les chemins par défaut dans js/script.js sont :
- caisse-calculator.jpg
- site-web.jpg
- automatisation.mp4
- marketing.jpg

Vous pouvez utiliser .png, .webp ou .mp4 également, mais adaptez le nom du fichier dans le tableau `projects` du fichier js/script.js.
Pour une vidéo, gardez `mediaType: 'video'`; pour une image, utilisez `mediaType: 'image'`.
Les catégories disponibles sont exactement : Web, Applications, Automatisation, Marketing.
